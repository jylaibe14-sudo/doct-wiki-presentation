降低假動態與進階解讀：Common-path、aLIV、Swiftness

要讓 dOCT 的時間變化更可信，除了演算法，也要控制光學系統的不穩定；進階指標則嘗試把動態幅度和活動快慢更清楚地區分。

學習目標

  • 知道外部震動如何造成假動態
  • 理解 common-path 對 D-FFOCT 的穩定性意義
  • 掌握 aLIV／Swiftness 的解釋界線

1. 物理世界也會讓訊號波動

雙光路干涉系統中的參考臂與樣品臂若受到不同程度的機械擾動，光程差改變就可能讓干涉訊號波動。即使樣品本身沒有對應的細胞活動，影像也可能顯示高動態對比。因此『先排除儀器與樣品運動』是合理解讀的前提。

  • 檢查震動、樣品晃動、配準及背景訊號。
  • 同時保留原始 OCT 與動態圖，避免只看彩色結果。

2. Common-path D-FFOCT 的貢獻

Lee 等人研究的是 full-field OCT（D-FFOCT）架構，將參考與樣品反射路徑設計得更共通，降低外界擾動對光程差的影響。在作者的指定實驗條件下，共光路設計展現更穩定的動態對比，論文摘要報告對噪聲的不敏感程度提高超過十倍。

  • 這是特定 D-FFOCT 系統及測試條件的結果。
  • 不能把『十倍』直接套用到所有 swept-source dOCT 設備。

3. 為什麼還需要 aLIV／Swiftness？

LIV 反映波動幅度，OCDS 反映相關衰減；但它們與樣品實際運動參數不一定是簡單線性關係。Morishita 等人提出模型化的 aLIV（asymptotic LIV）和 Swiftness 方法，嘗試提供對移動散射體佔比與活動快慢更可解釋的描述。

  • aLIV：與模型中動態散射體的佔比特徵相關。
  • Swiftness：與模型化動態快慢相關，不等於逐細胞追蹤的實際速度。
  • 必須注意擬合模型、可用時間範圍及訊雜比。

4. 如何安排下一次實驗？

先固定量測時序與相機／掃描參數，確認背景／靜態對照的波動，再設計一個改變細胞活動的對照條件；最後才比較 LIV、OCDS、aLIV 或 Swiftness。不同指標回答不同問題，不應只選顏色最明顯的一種當成唯一答案。

解讀界線

Common-path 是特定光學架構；aLIV／Swiftness 是模型化估計。兩者均不是所有 dOCT 系統或組織的通用保證。
